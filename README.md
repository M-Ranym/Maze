# 🧩 Maze

A Unity-based 3D maze game project. Navigate through procedurally styled environments, solve maze puzzles, and experience dynamic skybox lighting that shifts between day and night.

---

## 🎮 Overview

A Unity game project featuring:

- **Procedural maze navigation** — find your way through 3D maze environments
- **Dynamic skyboxes** — Cartoon-style day/night sky environments (AllSkyFree asset pack)
- **Custom lighting** — Skybox cubemap extended lighting for atmospheric rendering
- **Utility framework** — Boxophobic Utils for editor tooling and inspector styling

---

## 🛠️ Technology Stack

| Layer | Technology |
|-------|-----------|
| Game engine | Unity |
| Programming | C# |
| Skybox system | Boxophobic Skybox Cubemap Extended |
| Editor tools | Boxophobic Utils, Custom inspector GUIs |

## 📁 Repository Contents

- `Assets/` — Scenes, skybox environments, editor scripts, utilities
- `Assets/AllSkyFree/` — Cartoon day/night skybox environments (12 sky variants)
- `Assets/BOXOPHOBIC/` — Skybox cubemap extended shader, editor utilities
- `README_images/` — Day & night skybox previews

## 🚀 Running the Project

1. Open `My project.sln` in Unity
2. Restore packages (Window → Package Manager → Restore)
3. Open a scene from `Assets/` and press Play
